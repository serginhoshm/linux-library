# Debian Trixie

Compatibilidade confirmada para:
- Debian Trixie

## Scripts disponíveis
1. `flatpak-install.sh`
2. `flameshot-install.sh`
3. `ftp-setup.sh`
4. `nfs-client.sh`
5. `nfs-server.sh`
6. `plex-firewall-config.sh`
7. `samba-config.sh`
8. `samba-share.sh`
9. `signal-install.sh`
10. `swap-config.sh`
11. `transmission-config.sh`

## Uso rápido

```bash
chmod +x *.sh
sudo ./flatpak-install.sh
sudo ./flameshot-install.sh
```

## Observações
- Baseado em `apt` e `systemd`.
- Scripts adaptados para Debian Trixie.
- Use `sudo` sempre que o script necessitar de acesso administrativo.
